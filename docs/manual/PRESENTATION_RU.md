# Noid Messenger — Текст презентации (для визуализации)

> Текст по слайдам для презентации / видео / лендинга.
> На каждом слайде: заголовок, текст, визуальная подсказка.

## Слайд 1 — Титул
**Noid Messenger**
Ваши сообщения существуют только на ваших устройствах.
Визуал: тёмный герой-экран, два устройства обмениваются светящимся
зашифрованным потоком; иконок серверов нет вообще.

## Слайд 2 — Проблема
Современные мессенджеры — это почтовые отделения, читающие ваши письма.
Центральные серверы хранят plaintext, метаданные, контакты — навсегда.
Визуал: город картотек с табличкой «сервер» против тёмного щита.

## Слайд 3 — Идея
Без сервера. Без отдельного релей-сервиса. Один бинарник делает всё:
чат-клиент + узел DHT + релей + офлайн-почтовый ящик.
Визуал: одна иконка, разделённая на четыре подписанные роли.

## Слайд 4 — Безопасность в глубину
PIN (Argon2id) → мастер-ключ → AES-256-GCM в хранилище.
X3DH-рукопожатие → Double Ratchet на каждый контакт.
Noise-транспорт поверх QUIC/TCP/WebSocket.
KillPin мгновенно стирает всё.
Визуал: концентрические щиты вокруг устройства.

## Слайд 5 — Как пиры находят друг друга
Kademlia DHT: имена, подписанные prekey-бандлы, указатели mailbox.
Инвайт-коды несут адреса напрямую — инвайт → подключение → разговор.
Визуал: распределённая сеть узлов, часть подсвечена как релеи.

## Слайд 6 — Офлайн? Не проблема.
Зашифрованные конверты ждут в mailbox-узле — на другом клиенте Noid,
а не на центральном сервере. Сообщения переживают NAT, перезагрузки,
дни офлайна.
Визуал: запечатанный конверт на дружественном узле.

## Слайд 7 — Один код, все платформы
Windows · Linux/VPS · Android — одно ядро Rust, один стек крипто,
один формат файлов. Headless-узлы работают на любом VPS.
Визуал: три устройства, под ними светится общее ядро.

## Слайд 8 — Статус: промежуточно стабильная сборка (октябрь 2026)
Доставка Windows ↔ VPS проверена живьём: сессии, шифрование,
хранение, опустошение outbox. 328 тестов зелёных. Дальше — Android.
Визуал: чек-лист с отметками и стрелка вперёд.

## Слайд 9 — Открыт и проверяем
Rust + Svelte + Tauri. Воспроизводимые сборки, тестируемая криптография,
документированная модель угроз — читайте код и проверяйте сами.
Визуал: терминал с проходящим тест-сьютом.

## Слайд 10 — Итог
Noid: сообщения, которые принадлежат вам.
Визуал: баннер — круг с градиентом фиолет→зелёный, пульс в стиле ЭКГ.
